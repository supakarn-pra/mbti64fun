อ่านจากหน้า encyclopedia ทั้ง 64 แบบ เฉพาะส่วน **Overview** กับ **Work Style**
สรุปใหม่ด้วยคำของเราเอง ใช้เป็นวัตถุดิบปรับหน้าทำเนียบ 64 ตำแหน่ง
**ห้ามคัดลอกข้อความหรือชื่อตำแหน่งของเขามาใช้** — ชื่อตำแหน่งไทยของเราเขียนเองอยู่แล้ว ให้คงไว้

| ฟิลด์ | เรามีไหม | น่าหยิบมาใช้ไหม |

**โครงประโยคของ Overview เขาคงที่ทุกแบบ:** `ตอนทำงานคุณเป็นแบบนี้ → จุดที่มักสะดุด → โตขึ้นได้ด้วยการ...`
อันสุดท้ายคือ "ประโยคเติบโต" ซึ่งเป็นของดีที่หน้าเรายังไม่มีเลย

## 2. แพตเทิร์นสำคัญ — A/T × C/S สร้าง 4 บุคลิกย่อยที่คงที่ทุกแบบ

อันนี้คือของที่มีค่าที่สุดจากการอ่านทั้ง 64 แบบ ทุกตระกูลใช้สูตรเดียวกันหมด

| | **-C ทำงานกับทีม** | **-S ทำงานแบบมีขอบเขต** |
| --- | --- | --- |
| **A- นิ่ง มั่นใจ** | **เวอร์ชันโตเต็มวัย** เก่งและอยู่กับคนได้ เป็นเสาหลัก/ตัวประสาน ระวัง: ประนีประนอมจนช้า | **เวอร์ชันมั่นใจจัด** ฝีมือดีมากแต่ไม่แคร์ใคร ต้องการอิสระสูง ระวัง: มองข้ามคนอื่น สร้างศัตรู |
| **T- ละเอียด ไม่หยุดพัฒนา** | **เวอร์ชันทุ่มจนหมดตัว** ใจดี ดูแลคน แต่ขอการยอมรับ ระวัง: ปฏิเสธไม่เป็น เบิร์นเอาต์ ตัดสินใจช้า | **เวอร์ชันเก็บตัว** ฝีมือดีแต่ไม่เชื่อมั่นตัวเอง ระวัง: อยู่ในองค์กรยาก จมอยู่กับความสมบูรณ์แบบ |

ข้อสังเกตเพิ่ม
- **-TS หลายแบบเขาเขียนเป็นด้านมืดจริงจัง** บางอันถึงขั้นใส่วงเล็บว่า "ต้องฟื้นฟูสภาพจิตใจก่อน" — **เราไม่ควรทำแบบนั้น** เล่นกันในบริษัท ควรเขียนให้เป็นจุดแข็งที่มาพร้อมต้นทุน ไม่ใช่การวินิจฉัย
- **-AS กับ -TS จะได้สายงานเดี่ยว/ฟรีแลนซ์/ผู้เชี่ยวชาญ** ส่วน **-AC กับ -TC ได้สายทีม/ดูแลคน/ประสานงาน**
- คำว่า "โตขึ้นได้ด้วยการ..." ของแต่ละแบบ มักเป็นการยืมของจากช่องตรงข้ามในตาราง (คนสาย -S ต้องหัดสื่อสาร คนสาย -C ต้องหัดปฏิเสธ)

## 3. สรุป 64 ตำแหน่ง

`จุดแข็งในงาน` / `จุดที่ต้องระวัง` / `สายงานที่เหมาะ` — ย่อจาก Work Style ของเขา

### ☾ สายวิเคราะห์ (NT) — กลุ่มจอมมาร

| รหัส | จุดแข็งในงาน | จุดที่ต้องระวัง | สายงาน |
| --- | --- | --- | --- |
| INTJ-AC | เป็นสมองของทีม ไกล่เกลี่ยให้เถียงกันแบบมีประโยชน์ | ขัดเกลาแผนนานเกินจนไม่ได้เริ่ม | PM, ที่ปรึกษา, สถาปนิกระบบ |
| INTJ-AS | ออกแบบระบบใหญ่ได้เอง ไม่ยุ่งการเมืององค์กร | คิดว่าความเห็นคนอื่นไร้ค่า พูดตรงจนเจ็บ | นักวิจัยอิสระ, นักลงทุน, ที่ปรึกษากลยุทธ์ |
| INTJ-TC | วิเคราะห์ละเอียด เป็นตัวกลางที่ไม่ให้ทีมแตก | อยากให้แผนเพอร์เฟกต์และทุกคนเห็นด้วย เลยช้ามาก | วิเคราะห์ความเสี่ยง, Data Scientist, Compliance |
| INTJ-TS | ขุดหลักการลึก ๆ ได้ในงานที่ให้อิสระเต็มที่ | ไม่สนกฎองค์กร คิดจนหลุดจากโลกจริง | นักวิจัย, นักวิชาการ, นักเขียนเชิงทฤษฎี |
| INTP-AC | เป็นแหล่งไอเดียและคนแก้ปัญหา ใคร ๆ ก็เข้ามาปรึกษาได้ | อ่อนเรื่องแผนลงมือและงานประจำ คุยเพลินจนลืมเวลา | นักวิจัย, โปรแกรมเมอร์, ที่ปรึกษา |
| INTP-AS | ความเชี่ยวชาญสูงมากในงานที่ทำคนเดียวได้ | ประชุมเยอะ ๆ อยู่ไม่ได้ ไม่สนใจเรื่องคน | นักวิจัยพื้นฐาน, ฟรีแลนซ์เดฟ, สถาปนิกฐานข้อมูล |
| INTP-TC | เติมมุมมองหลากหลายในวงระดมสมอง | ไม่กล้าขายผลงานตัวเอง และเปลี่ยนความเห็นตามคนหมู่มาก | นักวิเคราะห์ข้อมูล, Technical Writer, บรรณาธิการ |
| INTP-TS | ลงลึกได้กับทฤษฎีที่ไม่มีใครแตะ | อยู่ในองค์กรยาก คิดจนไม่ได้ลงมือ | นักวิจัยเฉพาะทาง, นักปรัชญา |
| ENTJ-AC | ผู้นำที่ปลุกขวัญทีมได้ ดันลูกทีมให้โตด้วยงานที่ท้าทาย | ให้ประสิทธิภาพมาก่อนความรู้สึกคน หรือหาข้อสรุปนานจนพลาดจังหวะ | CEO, PM, ผู้บริหาร HR |
| ENTJ-AS | ลากองค์กรไปถึงเป้าด้วยคำสั่งบนลงล่าง เน้นผลลัพธ์และวินัย | ตัดคนที่ไม่ทำตามทิ้งจนมีศัตรูเยอะ ลูกทีมกดดันตลอด | CEO บริษัทใหญ่, ผู้ก่อตั้งสตาร์ตอัป, ทนายความ |
| ENTJ-TC | ผู้นำที่ใส่ใจลูกทีมรายคน | ความใจดีถูกมองว่าไม่เด็ดขาด และแบกทุกอย่างไว้คนเดียวจนหมดแรง | ผู้จัดการระดับกลาง, HR สายพัฒนาคน, ผู้ประสานโครงการ |
| ENTJ-TS | ดันผลลัพธ์ระยะสั้นได้แรงมาก | วิธีทำงานทำให้ลูกทีมหมดไฟ และหาคนร่วมงานจริง ๆ ยาก | ที่ปรึกษาพลิกฟื้นธุรกิจ, ผู้เชี่ยวชาญงานยาก |
| ENTP-AC | เครื่องปั่นไอเดียของทีม เก่งมากตอนเปิดโปรเจกต์ใหม่ | ความไม่อยู่ในกรอบกวนใจคนที่ชอบระเบียบ และลดความแรงของไอเดียลงเพราะเกรงใจ | ผู้ประกอบการ, ครีเอทีฟโฆษณา, ที่ปรึกษา |
| ENTP-AS | เก่งในงานที่ต้องทุบของเดิมสร้างของใหม่ | ถูกมองว่าอันตราย ต่อต้านหัวหน้า ดูถูกคนที่คิดช้ากว่า | ที่ปรึกษาอิสระ, ทนายว่าความ, นักวิเคราะห์ M&A |
| ENTP-TC | ทำให้วงระดมสมองคึกคัก เป็นที่เอ็นดูของผู้ใหญ่ | ใจเสียง่ายเวลาโดนติ และเปลี่ยนความเห็นตามคนอื่น | Planner, ครีเอทีฟงานอีเวนต์, พัฒนาสินค้า |
| ENTP-TS | พลังทุบของเดิมกลายเป็นนวัตกรรมได้ถ้าใช้ถูกทาง | อยู่ในองค์กรนาน ๆ ไม่ได้ มองทุกกฎเป็นเรื่องตลก | นักวิจารณ์สังคม, นักข่าวเชิงสืบสวน |

### ✦ สายอุดมคติ (NF) — วิหารแสง

| รหัส | จุดแข็งในงาน | จุดที่ต้องระวัง | สายงาน |
| --- | --- | --- | --- |
| INFJ-AC | เสาหลักทางใจของทีม มองออกว่าใครเก่งอะไรแล้วจัดที่ให้ | ฟังทุกคนจนตัดสินใจช้าและหลงทาง | ที่ปรึกษา, นักไกล่เกลี่ย, HR สายพัฒนาคน |
| INFJ-AS | เสนอสิ่งที่ควรแก้จริง ๆ โดยไม่เกรงอำนาจ | ถูกมองว่าอุดมคติเกินและไม่ร่วมมือ | นักเขียน, นักวิจัยอิสระ, นักสิทธิมนุษยชน |
| INFJ-TC | น้ำมันหล่อลื่นของทีม ช่วยเพื่อนจนงานตัวเองเสีย | รับงานเกินตัว เครียดง่ายในที่ที่แข่งกันดุ | นักจิตวิทยาคลินิก, นักสังคมสงเคราะห์, พยาบาล |
| INFJ-TS | คิดลึกและทำงานเดี่ยวเชิงลึกได้ดี | เข้ากับลำดับขั้นองค์กรไม่ได้ คิดจนไม่ได้ลงมือ | นักวิชาการ, กวี, นักวิจัยจิตวิทยาเชิงลึก |
| INFP-AC | ทำให้ทีมรู้สึกปลอดภัย ลดความตึงในห้องได้ | อยู่ในที่แข่งขันสูงลำบาก และผัดวันลงมือ | ที่ปรึกษา, ครู, นักเขียน, บรรณาธิการ |
| INFP-AS | ซื่อสัตย์กับค่านิยมตัวเองจนได้ใจคนบางกลุ่มเต็ม ๆ | ถูกมองว่าดื้อ และอยู่ในที่ที่ต้องฝืนความเชื่อไม่ได้ | นักเขียน, ศิลปิน, นักกิจกรรมสังคม |
| INFP-TC | คอยดูแลความรู้สึกคนในทีมให้ทุกคนอยู่สบาย | เสียสละจนตัวเองมาท้ายสุด และโทษตัวเองหนักเวลามีปัญหา | นักจิตวิทยา, นักไกล่เกลี่ย, บรรณารักษ์ |
| INFP-TS | มีต้นฉบับความคิดของตัวเองที่ไม่เหมือนใคร | งานประจำและงานที่ต้องคุยกันบ่อยไม่เหมาะเลย | กวี, นักแปลวรรณกรรม, ศิลปิน |
| ENFJ-AC | โค้ชที่ดันทีมทั้งทีมให้ผลงานดีขึ้น ผู้ใหญ่และลูกทีมไว้ใจ | รับผิดชอบเกินตัวเพราะอยากให้ทุกคนโอเค และซึมซับอารมณ์ลบของคนอื่น | ครู, ผู้จัดการ HR, PR/Marketing |
| ENFJ-AS | นำด้วยวิสัยทัศน์ชัดและมาตรฐานสูง | ยืนยันวิธีตัวเองจนคนต้าน และเร่งเป้าจนข้ามกระบวนการ | นักการเมือง, ผู้นำองค์กรสายปฏิรูป, ผู้ประกอบการเชิงอุดมการณ์ |
| ENFJ-TC | ทุ่มพัฒนาลูกทีมและดีใจกับความสำเร็จของเขาจริง ๆ | เข้าไปแก้ปัญหาคนอื่นลึกเกิน เหนื่อยจากงานอารมณ์ และไม่ยอมรับผลงานตัวเอง | ที่ปรึกษา, ครูสอนตัวต่อตัว, HR สายดูแลพนักงาน |
| ENFJ-TS | กล้าชนกับสิ่งที่ไม่ถูกต้องในองค์กร | ถูกฝ่ายที่อยากอยู่นิ่ง ๆ หมายหัว และหมดไฟเมื่อเจอช่องว่างระหว่างอุดมคติกับความจริง | นักข่าวเชิงสืบสวน, NGO, ทนายสายสิทธิ |
| ENFP-AC | ตัวจุดพลังของทีม ตื่นเต้นกับของใหม่เร็วกว่าใคร | สนใจหลายอย่างจนเลือกทางไม่ได้ และรำคาญตัวเองที่ยังไม่เป็นรูปเป็นร่าง | PR, Marketing, Copywriter, จัดอีเวนต์ |
| ENFP-AS | เปล่งประกายในที่ที่เปลี่ยนเร็วและให้ตัดสินใจเอง | ถูกสั่งจากบนลงล่างหรือไมโครแมเนจแล้วอยู่ไม่ได้ งานประจำไม่ไหว | ครีเอเตอร์อิสระ, ที่ปรึกษาอิสระ, พัฒนาธุรกิจใหม่ |
| ENFP-TC | ปลุกใจทีมและมองเห็นแวว ๆ ในตัวคนอื่น | โดนอารมณ์คนอื่นดูดพลัง ช่วยเกินขอบเขตงานตัวเอง | Career Coach, ที่ปรึกษาการศึกษา, NGO |
| ENFP-TS | สร้างสรรค์จัดในที่ที่ปล่อยให้คิดอิสระ | ไม่เชื่อในพรสวรรค์ตัวเอง และชนกับบรรทัดฐานสังคมจนโดดเดี่ยว | ศิลปินแนวทดลอง, ผู้กำกับอิสระ, นักเขียนอิสระ |

### ♛ สายดูแลระบบ (SJ) — ราชวัง

| รหัส | จุดแข็งในงาน | จุดที่ต้องระวัง | สายงาน |
| --- | --- | --- | --- |

## 4. ข้อเสนอสำหรับหน้าทำเนียบของเรา

**ทำเลย — ของที่หน้าเรายังขาดและได้ผลเยอะ**
1. เพิ่ม 3 ฟิลด์ต่อตำแหน่งจากตารางข้างบน: `จุดแข็งในทีม` / `จุดที่ต้องระวัง` / `สายงานที่เหมาะ` เขียนใหม่ให้เข้าธีมแฟนตาซี-ออฟฟิศ
2. การ์ดในทำเนียบยังโชว์แค่ชื่อกับคำโปรยเหมือนเดิม แต่**กดแล้วขยายดูรายละเอียด** จะได้ไม่ยาวเกิน
3. เพิ่ม **"ประโยคเติบโต"** ต่อตำแหน่ง (แบบ "โตขึ้นได้ด้วยการ...") — ของเขามีทุกแบบและเป็นท่อนที่อ่านแล้วได้อะไรกลับไปจริง ๆ

**ทำทีหลังได้**
4. ฟิลเตอร์ในทำเนียบ: กรองตามสังกัด / ตามตัวอักษร A-T / C-S
5. หน้าเช็คคู่ (`compatibleTypes`) — สนุกสำหรับเล่นในทีม
6. ส่วน "อะไรทำให้เครียด + รับมือยังไง" (`stressManagement`)

**อย่าทำ**
- อย่าลอกชื่อตำแหน่งหรือข้อความของเขา — ของเราเขียนเองหมดแล้ว ให้คงไว้
- อย่าใส่รายชื่อคนดังประจำแบบ
- อย่าเขียนกลุ่ม `-TS` เป็นด้านมืดแบบเขา เล่นกันในบริษัทควรให้ทุกแบบมีศักดิ์ศรีเท่ากัน
