# 64 ตำแหน่งในต่างโลก

แบบทดสอบบุคลิกภาพ 90 ข้อ ภาษาไทย ทำเล่นกันในทีม — ตอบครบแล้วได้ "ตำแหน่ง" ในโลกแฟนตาซี
1 ใน 64 แบบ พร้อมสังกัด (กิลด์ผู้กล้า / ราชวัง / วิหารแสง / กลุ่มจอมมาร) และค่าสถานะ 6 แกน

> ทำขึ้นเพื่อความสนุก ไม่ใช่เครื่องมือวัดผลทางจิตวิทยา ไม่เกี่ยวข้องกับ MBTI®
> และไม่ควรใช้ตัดสินใจเรื่องการจ้างงานหรือประเมินผลคนจริง ๆ

## 3 โหมด

| โหมด | ทำอะไร |
| --- | --- |
| แบบทดสอบใหม่ | ทำครบ 90 ข้อ วัดใหม่ทั้ง 6 แกน |
| เทียบกับร่างเก่า | กรอกผลที่เคยได้ (`ENFP` / `ENFP-T` / `ENFP-TC`) แล้วทำ 90 ข้อ ผลจะเทียบให้ทีละตัวอักษรว่าตัวไหนเปลี่ยน |
| อัพเกรดร่างเดิม | กรอก 4 ตัวแรกที่เคยได้ วัดเพิ่มเฉพาะจิตใจ (A/T) กับความผูกพัน (C/S) |

เลือกความยาวได้ทั้ง 3 โหมด — **เต็มยศ** (แกนละ 15 ข้อ) หรือ **รีบไปทำงาน** (แกนละ 5 ข้อ)

| | เต็มยศ | รีบไปทำงาน |
| --- | --- | --- |
| ทำใหม่ / เทียบกับร่างเก่า | 90 ข้อ | 30 ข้อ |
| อัพเกรดร่างเดิม | 30 ข้อ | 10 ข้อ |

มีปุ่มกลับบ้านระหว่างทำ (ไม่ล้างคำตอบ กดโหมดเดิมเข้ามาใหม่ทำต่อจากข้อที่ค้างไว้)
และหน้าทำเนียบรวมทั้ง 64 ตำแหน่ง แบ่งตาม 4 สังกัด

## โครงสร้าง

- 6 แกน × 15 ข้อ = 90 ข้อ ตอบทีละข้อ เลือก 4 ระดับ (กดคีย์ 1–4 ได้)
- 2^6 = 64 ตำแหน่ง — คำถามและคำบรรยายทั้งหมดเขียนขึ้นใหม่เป็นภาษาไทย
- แก้คำถาม/ตำแหน่งได้ที่ [`src/data/quiz.js`](src/data/quiz.js) ไฟล์เดียว
- build ออกมาเป็น `dist/index.html` ไฟล์เดียวจบ ไม่มี asset แยก เอาไปวางที่ไหนก็ได้

## รัน

```bash
npm install
npm run dev     # แก้สด
npm run build   # ได้ dist/index.html
```

## หมายเหตุเรื่องภาษาไทย

- ต้องมี `<meta charset="utf-8">` ไม่งั้นภาษาไทยเพี้ยนทั้งหน้า
- ตัดคำด้วย `Intl.Segmenter` ตอน build แล้วคั่นด้วย zero-width space
  เพื่อให้ webview ที่ไม่มีพจนานุกรมไทยไม่ตัดบรรทัดกลางคำ
- อย่าใส่ `letter-spacing` กับข้อความไทย สระและวรรณยุกต์จะลอยห่างจากตัวอักษร
